# Practical 1: React Router Navigation

## Aim
Develop a React application that uses `BrowserRouter`, `Route`, and `Link` to navigate between Home, About, and Contact pages without reloading the entire webpage.

## Description
In this practical, we implement client-side routing using the `react-router-dom` library. React Router updates the browser URL and swaps components dynamically without sending a new request to the server or reloading the whole page.

## Components Created
- `Navbar.jsx`: Contains navigation links (`<Link to="...">`) to switch routes.
- `Home.jsx`: Landing page component.
- `About.jsx`: Information page explaining router concepts.
- `Contact.jsx`: Contact form with simple state handling.
- `App.jsx`: Sets up `<BrowserRouter>`, `<Routes>`, and `<Route>` mappings.

## How to Run
```bash
npm install
npm run dev
```
