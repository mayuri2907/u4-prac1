# Practical 1: React Router Navigation (Unit 4)

## Aim
Develop a React application that uses `BrowserRouter`, `Route`, and `Link` to navigate between Home, About, and Contact pages without reloading the entire webpage.

## GitHub Repository
`https://github.com/mayuri2907/u4-prac1.git`

## Features & Implementation
- **BrowserRouter**: Supplies the HTML5 history routing context.
- **Routes & Route**: Matches paths (`/`, `/about`, `/contact`) to render components dynamically.
- **Link**: Client-side navigation that prevents browser page reloads.
- **Tailwind CSS**: Clean light theme styling with zero external UI bloat.

## How to Run Locally
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```
